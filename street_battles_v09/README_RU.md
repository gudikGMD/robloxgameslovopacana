# Уличные бои v0.9 — дэш и реакции на удары

Обновление создано на основе загруженного вами архива v0.8. Сохраняются карта, 6 персонажей, их предметы, лидерборды и выбор бойца.

## Что исправлено
- Q: вместо разового задания скорости используется LinearVelocity на 0.23 секунды, с проверкой стены, кулдауном 3 секунды и анимацией.
- Удары по игроку: сервер посылает реакцию на попадание, анимация имеет 3 варианта отшатывания, локальная камера пострадавшего слегка вздрагивает.
- Анимация дэша: две фазы движения корпуса и ног.

## Установка (подробно)
1. В Roblox Studio сделайте File → Save to File, чтобы сохранить резервную копию.
2. В Explorer откройте ServerScriptService, дважды нажмите StreetBattles. Ctrl+A, Delete. Откройте из архива ServerScriptService/StreetBattles.server.lua в Блокноте, Ctrl+A, Ctrl+C, вернитесь в Studio, Ctrl+V.
3. В Explorer откройте StarterPlayer → StarterPlayerScripts, дважды нажмите R6Animations. Замените весь код из StarterPlayerScripts/R6Animations.client.lua.
4. Там же дважды нажмите StreetUI и замените код из StarterPlayerScripts/StreetUI.client.lua.
5. GameConfig, Courtyard и Leaderboards НЕ МЕНЯТЬ, если у вас уже установлена v0.8. Если нет — файлы есть в архиве.
6. Убедитесь, что игра настроена на R6, нажмите Play, протестируйте Q и попадания по второму игроку (Test → Start 2 Players). Откройте Output для ошибок. После проверки File → Publish to Roblox.

## Ограничения
Код не запускался в Roblox Studio из этой среды. Анимации процедурные, через Motor6D, а не профессиональные Animation Editor clips; качество The Strongest Battlegrounds требует ручной покадровой анимации и дополнительной постановки каждого уникального приёма. Если дэш блокируется окружением или вы видите ошибки в Output, пришлите скриншот и описание.
